# 1. Project Name : Dev Stack

## 2. Project Discription : Dev Stack is a responsive web app that helps developers explore technologies and build their ideal development stack

## 3. Technologies Used : React, TypeScript, Vite, Tailwind CSS, React Toastify, JSON etc

## 4. 3main Feature : 01 Technology Explore, 02 Stack create, 03 Add/Remove + Toast notification

5 Qustion Answer ->
   01 What is JSX, and why is it used in React?
   Ans : JSX lets us write HTML-like code inside JavaScript/TypeScript. It makes React UI easier to write and understand.

  02 What is the difference between props and state?
  Ans : Props are data passed from a parent to a child. State is data managed and changed inside a component.

  03 What does the useState hook do?
  Ans : useState stores and updates component data. I used it for the selected technology stack and mobile menu.

  04 What does the useEffect hook do?
  Ans : useEffect runs side effects after rendering. I used it for the loading process of the technology data.

 05 Why does every item in a .map() list need a unique key prop?
 Ans : A unique key helps React identify and efficiently update each list item.

06 What is conditional rendering?
Ans : Conditional rendering shows different UI based on a condition. For example, I show an empty message when the stack has no items.

07 How do you pass data from a parent to a child component?
 Ans : The parent passes data through props. A child can send data back by calling a callback function passed through props.
